every action below is a real menu item whose accelerator you can rebind in
**settings → shortcuts**. the defaults are listed here. modifier keys follow
macOS conventions: Cmd, Shift, Alt (Option), Ctrl.

## tabs

| action | shortcut |
|---|---|
| new tab | Cmd+T |
| close tab | Cmd+W |
| reopen closed tab | Cmd+Shift+T |
| duplicate tab | Cmd+Shift+K |
| pin or unpin tab | Cmd+Shift+P |
| next tab | Cmd+Shift+] |
| previous tab | Cmd+Shift+[ |
| switch to tab 1 to 8 | Cmd+1 ... Cmd+8 |
| switch to last tab | Cmd+9 |

## navigation

| action | shortcut |
|---|---|
| focus address bar | Cmd+E |
| back | Cmd+[ or Cmd+Left |
| forward | Cmd+] or Cmd+Right |
| reload tab | Cmd+R |
| reload (bypass cache) | Cmd+Shift+R |
| copy current URL | Cmd+Shift+C |
| open command palette | Cmd+L |

## find and zoom

| action | shortcut |
|---|---|
| find in page | Cmd+F |
| find next match | Cmd+G |
| find previous match | Cmd+Shift+G |
| zoom in | Cmd+= |
| zoom out | Cmd+- |
| reset zoom | Cmd+0 |

## panes

| action | shortcut |
|---|---|
| split pane right | Cmd+D |
| split pane down | Cmd+Shift+D |
| focus pane left | Alt+Cmd+Left |
| focus pane right | Alt+Cmd+Right |
| focus pane up | Alt+Cmd+Up |
| focus pane down | Alt+Cmd+Down |
| close pane | Alt+Cmd+W |
| unsplit panes | Alt+Cmd+U |

## workspaces and windows

| action | shortcut |
|---|---|
| new window | Cmd+N |
| new private window | Cmd+Shift+N |
| new workspace | Alt+Cmd+N |
| next workspace | Alt+Cmd+E |
| previous workspace | Alt+Cmd+Q |

## tools and panels

| action | shortcut |
|---|---|
| show bookmarks | Alt+Cmd+B |
| bookmark this page | Cmd+Shift+B |
| show downloads | Cmd+J |
| show history | Cmd+Shift+H |
| open settings | Cmd+, |
| clear browsing data | Cmd+Shift+Backspace |
| toggle floating sidebar | Cmd+S |
| hide element (picker) | Cmd+Shift+X |
| print page | Cmd+P |
| pop out video | Cmd+Shift+O |

:::tip
to rebind any of these, open **settings → shortcuts**, click the binding, and
press the new combination. wis flags conflicts so two actions never silently
share a shortcut.
:::
